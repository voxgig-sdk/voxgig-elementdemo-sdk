## Regenerate this target

```bash
cd ../.sdk
npm run build        # only if you changed a component
npm run generate     # refreshes this java/ directory
```

Then build and test the generated output:

```bash
# in this target directory (java/):
make build
make test
```


## What generates this target

| Source | Path | Edit when… |
| --- | --- | --- |
| Target definition | `.sdk/model/target/java.aontu` | deps, module, extension, phases change |
| Templates | `.sdk/tm/java/` | the file is the **same for every API** (runtime, transport, base classes) — copied verbatim with placeholder substitution |
| Components | `.sdk/src/cmp/java/` | the file's shape **depends on the API** (entities, constructor, README, tests) — TypeScript that walks the model |

Decision rule: *same for every API → template; depends on the API →
component.* After editing a component run `npm run build` before
`npm run generate`; template-only edits just need `npm run generate`.
